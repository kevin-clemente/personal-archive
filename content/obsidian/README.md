# Obsidian snapshot

`My Watch Collection.md` is the published note that produced the committed
`app/generated-notes.ts` entry. It is kept here as a repository snapshot so the
site has a source record without iCloud access.

The live watch data does **not** come from this file. It is imported from the
structured notes in the Kvan vault:

- `Watches/Owned/*.md`
- `Watches/Wishlist/*.md`
- `Watches/Grail/*.md`
- `Watches/00 - Watch Collection.md` for the overview, purchase plan, strategy
  and collecting rules

Run `npm run sync:obsidian` after editing those notes. See the “Watches”
section of the root `README.md` for the frontmatter and photo conventions.
